Enclave Help

AES-256-GCM file encryption for Windows · Version 1.7.0 (build 19)

Enclave encrypts files and folders with a password. By default the original filename is also encrypted, and the saved .enclave name is a 32-character SHA-512 fingerprint. Turn off Encrypt filename to keep the original name in the archive and on disk.

Works with the Mac version. Enclave uses the same file format on Windows and macOS, so a .enclave file made on one will open on the other with the same password.

Quick Start

  1. Type your password.
  2. Leave Encrypt filename on (default) to hide the name, or turn it off to keep it visible.
  3. Drag a file or folder onto the window, or click Choose File… or Choose Folder…
  4. Click Encrypt or Decrypt.
  5. Choose where to save the result.

Double-clicking a .enclave file opens Enclave with that file already loaded and the cursor in the password box — just type the password and click Decrypt.

Folder Encryption

Folders are packed into an ENCLPKG1 bundle (original paths preserved), then encrypted as a single .enclave archive. With filename encryption on, the internal name ends with .enclavefolder. With it off, the archive uses the plain folder title (for example, Projects.enclave).

  • Decrypting a folder archive asks for a parent folder; Enclave re-creates the original folder inside it.
  • Symbolic links, junctions, and hidden files (names starting with .) are skipped when packing.
  • Decrypt will not overwrite an existing, non-empty destination folder.
  • Per-file and total size limits apply (the same maximum as a single encrypted file).

How It Works

  • AES-256-GCM encrypts the file contents. The filename is encrypted by default (plaintext mode optional).
  • The header is authenticated as AES-GCM additional data. Tampering with the version, flags, key-derivation block, or salt makes decryption fail. From v5, the stored filename is authenticated too — even in plaintext mode — so altering it is detected.

Algorithms

Enclave uses different algorithms for different jobs — SHA-512 is not used to derive keys for new files.

  • Key derivation (new files): Argon2id (BLAKE2b internally) from your password and a 32-byte random salt. Default: 65,536 KiB memory, 3 iterations, 1 lane (~64 MiB RAM per operation).
  • Key derivation (older v3): PBKDF2-HMAC-SHA256. The iteration count is stored in the header and stays decryptable.
  • Key derivation (v2 legacy): HKDF-SHA512. Decrypt-only; re-encrypt to upgrade.
  • On-disk filename only: SHA-512 over salt + encrypted-filename; the first 32 hex digits become the .enclave name. This hides the real filename — it does not strengthen your password.
  • Encryption: AES-256-GCM with authentication tags.

File Format

  • Magic: ENCLAVE1 (8 bytes). Current version: v5.
  • v5: magic → version (5) → flags (bit 0 = encrypt filename) → KDF id → KDF length → KDF params → 32-byte salt → filename blob → encrypted file blob. The file blob authenticates the header and the filename.
  • v4: same layout, but only the header is authenticated. Still decryptable.
  • v3: like v4 without the flags byte; filename always encrypted.
  • KDF ids: 1 = PBKDF2-HMAC-SHA256, 2 = Argon2id (default for new files).
  • v2: salt-only header, HKDF-SHA512, no header authentication. Still decryptable; re-encrypt to upgrade.
Performance: Argon2id deliberately uses memory and CPU time to slow offline password guessing, so expect a short pause on each operation.

Command Line (optional)

Most people can ignore this and just use the app. If you want it, a console version enclave-cli.exe is produced under src\EnclaveCli\bin\Release\net8.0 when you build:

enclave-cli encrypt myfile.pdf -p "your-password"
enclave-cli encrypt myfile.pdf -p "your-password" --plaintext-filename
enclave-cli decrypt a3f8b2c1....enclave -p "your-password"
enclave-cli selftest

If you leave off -p, it asks for the password without showing it.

Password Tips

  • Use a long, unique password you can remember or keep in a password manager.
  • If you forget the password, the file cannot be recovered.
  • Avoid -p password on shared computers — it can appear in process lists. Let the command line prompt you instead.
Security note: Enclave protects files at rest. Keep backups of important data and store passwords safely.
